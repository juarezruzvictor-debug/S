Ejercicio: encuentra el bug y despliega la solución
Contexto
Esta es una landing page sencilla (HTML + CSS) para EIG Campus. Tiene un bug visual introducido a propósito: en algún punto de la página hay texto que no se ve porque su color coincide con el color de fondo.

Tu tarea
Haz un fork o clona este repositorio.
Abre index.html en tu navegador (puedes usar Live Server, por ejemplo).
Recorre toda la página con atención: hay un elemento de texto invisible.
Usa las herramientas de desarrollador del navegador (clic derecho → Inspeccionar → pestaña Styles) para localizar la regla CSS responsable.
Corrige styles.css.
Haz commit de tu solución con un mensaje descriptivo.
Despliega la versión corregida (por ejemplo con GitHub Pages: Settings → Pages → Deploy from branch) y comparte el enlace público.
Criterios de evaluación
El bug ha sido identificado correctamente.
La corrección en styles.css soluciona el problema sin romper el resto del diseño.
El historial de commits es claro (al menos un commit describiendo el fix).
La web queda desplegada y accesible públicamente.
